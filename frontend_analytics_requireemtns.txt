# 📊 Analytics Dashboard: Backend API & Data Requirements

## 1. **Overview**

The analytics dashboard provides real-time and historical insights for mall management, including:
- Real-time metrics (visitors, dwell time, active cameras)
- Heatmaps (zone-wise density)
- Section/rack analytics
- Customer insights (demographics, peak hours)
- Camera monitoring
- Alerts & notifications

To support these features, the backend must expose a set of RESTful and WebSocket APIs, with flexible filtering and efficient data structures.

---

## 2. **API Endpoints & Data Contracts**

### 2.1. **Mall Analytics (Summary)**
**Endpoint:**  
`GET /analytics/mall/{mall_id}?range={hour|day|week|month}`

**Returns:**  
```json
{
  "totalVisitors": 1245,
  "activeVisitors": 45,
  "averageDwellTime": 45,
  "peakHours": ["10:00-11:00", "14:00-15:00"],
  "popularSections": [
    { "name": "Electronics", "visitorCount": 320 },
    { "name": "Clothing", "visitorCount": 290 }
  ]
}
```

**Filters:**
- `range`: hour, day, week, month (default: day)
- (Optional) `gender`, `ageGroup`, `zone`, `cameraId`

---

### 2.2. **Real-Time Metrics**
**Endpoint:**  
`GET /analytics/mall/{mall_id}/realtime`

**Returns:**  
```json
{
  "activeVisitors": 45,
  "currentPeakHour": false,
  "timestamp": "2024-06-10T12:34:56Z"
}
```

---

### 2.3. **Heatmap Data**
**Endpoint:**  
`GET /analytics/mall/{mall_id}/heatmap?range={hour|day|week|month}`

**Returns:**  
```json
{
  "mallId": 1,
  "zones": [
    {
      "name": "Electronics",
      "visitorCount": 150,
      "coordinates": [[20, 30], [40, 50], ...], // Polygon for zone
      "density": 0.8
    }
  ],
  "timestamp": "2024-06-10T12:34:56Z"
}
```

**Filters:**
- `range`
- `gender`
- `ageGroup`
- `timeOfDay`
- `zone`

---

### 2.4. **Section/Rack Analytics**

### 2.8. **Alerts & Notifications (Real-Time)**
**Endpoint:**  
`GET /analytics/mall/{mall_id}/alerts?since={timestamp}`  
or via **WebSocket**:  
`ws://.../ws/analytics/{mall_id}`

**Returns:**  
```json
[
  {
    "id": 1,
    "type": "high_traffic",
    "message": "High traffic detected in Electronics section",
    "severity": "warning",
    "zone": "Electronics",
    "time": "2024-06-10T12:34:56Z"
  }
]
```

---

### 2.9. **Time Series Data (for Graphs)**
**Endpoint:**  
`GET /analytics/mall/{mall_id}/timeseries?metric=visitors&range=day`

**Returns:**  
```json
[
  { "time": "09:00", "visitors": 45, "interactions": 120 },
  { "time": "10:00", "visitors": 78, "interactions": 210 }
]
```

**Filters:**
- `metric`: visitors, interactions, dwellTime, etc.
- `range`
- `zone`
- `cameraId`

---

## 3. **Filters & Query Parameters**

- **Time Range:** `range=hour|day|week|month`
- **Zone/Section:** `zone=Electronics`
- **Rack:** `rack=Rack 1`
- **Gender:** `gender=male|female|all`
- **Age Group:** `ageGroup=18-25|26-35|36-45|46-55|55+`
- **Camera:** `cameraId=1`
- **Metric:** `metric=visitors|interactions|dwellTime`
- **Time of Day:** `timeOfDay=morning|afternoon|evening|night`

---

## 4. **WebSocket (for Real-Time Updates)**

- **Connect:** `ws://.../ws/analytics/{mall_id}`
- **Events:**
  - `analytics_update` (summary, heatmap, timeseries)
  - `alert` (new alert/notification)
  - `visitor_update` (real-time visitor count)

---

## 5. **Data Structure Summary**

- **MallAnalytics:** summary stats, popular sections, peak hours
- **HeatmapData:** zone polygons, visitor counts, density
- **SectionAnalytics:** per-section/rack stats, gender split, dwell time
- **CustomerStats:** demographic breakdowns
- **CameraAnalytics:** per-camera stats, health, last active
- **Alert:** id, type, message, severity, zone, time
- **TimeSeries:** time, visitors, interactions

---

## 6. **Example Dashboard Data Flow**

1. **On load:**  
   - Fetch `/analytics/mall/{mall_id}` for summary
   - Fetch `/mall/{mall_id}/cameras` for camera list
   - Fetch `/analytics/mall/{mall_id}/heatmap` for heatmap
   - Fetch `/analytics/mall/{mall_id}/timeseries` for graphs

2. **On filter change:**  
   - Re-fetch with new query params (e.g., `?range=week&zone=Electronics`)

3. **For real-time:**  
   - Open WebSocket, listen for `analytics_update`, `alert`, `visitor_update`
